# About

## Preface

The OWASP Robotics Security Testing Guide (RSTG) is a comprehensive manual for testing the security of cyber-physical systems, robotic platforms, and embodied AI. This guide is built by the community, for the community, aiming to establish a standardized baseline for robotics penetration testing, focusing uniquely on the intersection of software security and kinetic physical safety.
